# Dosher Fitness & Martial Arts — demo site

Concept demo by Palmetto AI Automation for Dosher's Fitness & Martial Arts, 2869 Holden Beach Rd, Supply, NC.

Static site, no build step: `index.html`, `assets/site.css`, `assets/site.js`, photos in `assets/img/` (from the gym's Facebook page and dosherfitness.com).

- Class schedule data lives in `SCHEDULE` at the top of `assets/site.js` (from the schedule graphic posted on Facebook; confirm with the gym).
- No contact form on purpose: visitors call, text, email or message on Facebook directly.
- `noindex` while it's a demo.
